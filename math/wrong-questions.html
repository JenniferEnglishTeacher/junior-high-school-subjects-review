重點：AB＝0 ⇒ A＝0 或 B＝0；兩邊有相同因式：移項、提公因式，不可直接約分；「一元二次」⇒ 二次項係數 ≠ 0

兩邊有相同因式

關於方程式 (2x＋1)(x－1)＝(3x＋2)(x－1) 的根，下列敘述何者正確？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：C

⚠ 不可以兩邊同除以 (x－1)：x－1 可能等於 0，除掉會漏根。
移項：(2x＋1)(x－1)－(3x＋2)(x－1)＝0
提出公因式：(x－1)[(2x＋1)－(3x＋2)]＝0
化簡：(x－1)(－x－1)＝0
x－1＝0 或 －x－1＝0 → x＝1 或 x＝－1
兩根一正一負，選 (C)。

解題關鍵：兩邊有相同因式時，要「移項、提公因式」，不能直接約分。

已知一根為 0

若一元二次方程式 (k－2)x²＋4x＋k²－4＝0 有一根為 0，則 k 的值為何？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：A

把 x＝0 代入：(k－2)·0²＋4·0＋k²－4＝0
k²＝4 → k＝2 或 k＝－2
但這是「一元二次方程式」，x² 的係數 k－2 ≠ 0 → k ≠ 2
所以 k＝－2，選 (A)。

解題關鍵：一元二次方程式 ⇒ 二次項係數不可為 0，算完要檢查。

已知一根為 0，求參數與另一根

若一元二次方程式 (a＋2)x²－2ax－(a²－a－6)＝0 恰有一根為 0，則 a 的值與方程式的另一解為何？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：A

(1) 求 a：把 x＝0 代入 → －(a²－a－6)＝0
a²－a－6＝0 → (a－3)(a＋2)＝0 → a＝3 或 a＝－2
二次項係數 a＋2 ≠ 0 → a ≠ －2，所以 a＝3
(2) 求另一解：a＝3 代回
5x²－6x－(9－3－6)＝0 → 5x²－6x＝0
x(5x－6)＝0 → x＝0 或 x＝6/5
另一解為 6/5，選 (A)。

解題關鍵：代 0 求參數 → 檢查二次項係數 → 代回求另一根。

整數根

若一元二次方程式 x²＋kx＋6＝0 的兩根皆為整數，則下列何者「不可能」為 k 的值？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：B

設兩整數根 p、q：x²＋kx＋6＝(x－p)(x－q) → pq＝6，k＝－(p＋q)
列出乘積為 6 的整數組：
1 × 6 → 和 7 → k＝－7
2 × 3 → 和 5 → k＝－5
(－1)×(－6) → 和 －7 → k＝7
(－2)×(－3) → 和 －5 → k＝5
k 只可能是 ±5、±7，不可能是 1，選 (B)。

解題關鍵：整數根：先列出常數項的所有因數組（包含負數），再算 k。

看錯係數

石頭與春梅兩人同解方程式 2x²＋bx＋c＝0，石頭看錯 c，解得兩根為 －4、2；春梅看錯 b，解得兩根為 －1、3，則下列敘述何者正確？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：D

石頭看錯 c，但 b 是對的：用他的根還原 → 2(x＋4)(x－2)＝2x²＋4x－16 → b＝4
春梅看錯 b，但 c 是對的：用她的根還原 → 2(x＋1)(x－3)＝2x²－4x－6 → c＝－6
（記得乘回首項係數 2！）
原方程式：2x²＋4x－6＝0 → x²＋2x－3＝0
(x＋3)(x－1)＝0 → x＝－3 或 x＝1，選 (D)。

解題關鍵：看錯誰就不用誰：用另一人的根還原「沒看錯」的係數。

質數根

已知方程式 x²－15x＋m＝0 的兩根皆為質數，求 m 的值為何？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：B

設兩質數根 p、q：x²－15x＋m＝(x－p)(x－q) → p＋q＝15，pq＝m
兩個奇數相加是偶數；和是 15（奇數）→ 其中一個必是偶質數 2
另一根＝15－2＝13（是質數 ✓）
m＝2×13＝26，選 (B)。

解題關鍵：兩質數和為奇數 ⇒ 其中一個一定是 2。

整數根與二位數

若一元二次方程式 x²＋ax－18＝0 的兩根均為整數，且正整數 a 為二位數，則 a 的個位數字與十位數字之和為何？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：A

設整數根 p、q：pq＝－18，a＝－(p＋q)
(1, －18) → a＝17　(－1, 18) → a＝－17
(2, －9) → a＝7　(－2, 9) → a＝－7
(3, －6) → a＝3　(－3, 6) → a＝－3
正的二位數只有 a＝17 → 1＋7＝8，選 (A)。

解題關鍵：列出所有因數組，再挑出符合條件（正、二位數）的 a。

相反數根與重根

已知一元二次方程式 x²＋(m＋2n)x－9＝0 的兩根互為相反數，且方程式 4x²＋4x＋(2m＋3n)＝0 有重根，則 m＋n 之值為何？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：A

兩根互為相反數 r、－r：(x－r)(x＋r)＝x²－r²，沒有 x 項
→ 一次項係數 m＋2n＝0 ……①
有重根 → 左式是完全平方：(2x＋1)²＝4x²＋4x＋1
→ 2m＋3n＝1 ……②
由① m＝－2n，代入②：－4n＋3n＝1 → n＝－1，m＝2
m＋n＝2＋(－1)＝1，選 (A)。

解題關鍵：相反數根 ⇒ 一次項係數＝0；重根 ⇒ 完全平方式。

某考生解一元二次方程式時，不慎將一次項係數的正負號看錯，解得兩根為 －4 和 3，則此方程式正確的兩根為何？

平方根與年齡

佩盈想知道老師的年齡，老師說：「我的年齡的平方根是 2x＋4 與 x²＋4x－11，且 x＞0，請妳算出我今年幾歲吧！」求老師的年齡為何？

🧭 引導解題：不會嗎？跟著提問一步一步想

正確答案：A

一個正數有兩個平方根，而且「互為相反數」→ 兩個平方根相加＝0
(2x＋4)＋(x²＋4x－11)＝0 → x²＋6x－7＝0
(x＋7)(x－1)＝0 → x＝1（x＞0，－7 不合）
兩個平方根：2×1＋4＝6，1＋4－11＝－6 ✓（互為相反數）
年齡＝6²＝36 歲，選 (A)。

解題關鍵：「a 的平方根是 A 與 B」⇒ A＋B＝0，不是 A＝B。

已知阿德出生於西元 1980 年，且經過 x 年後，正好是西元 x² 年，則 x＝？

🧭 引導解題：不會嗎？跟著提問一步一步想

相同長方形重疊

如圖，小庭將兩個相同的長方形 ABCD 與 EFGH 疊在一起。若四邊形 EICJ 也是長方形，且 BI＝x²，IF＝2x－2，JH＝－2x＋8，則 x 的值為何？
